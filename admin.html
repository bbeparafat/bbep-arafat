01 / CONNECT

Connect your GitHub account

Only the bbeparafat GitHub account can publish here. Your Gmail password is not used.

Use a token restricted to bbep-arafat, with Contents: Read and write. Set an expiry. Never paste it into website code or chat.

First-time setup — create the token
  1. Open GitHub fine-grained tokens and sign in as the website owner.
  2. Choose an expiry, and select Only select repositories → bbep-arafat.
  3. Under Repository permissions, set Contents → Read and write. Leave other optional permissions off.
  4. Generate the token and paste it above. If your workflow requires extra permissions or approval, stop and check the exact error rather than granting broad account access.

The token stays in this tab’s memory only. It is never saved in cookies, browser storage, the repository, or the public website. Closing or refreshing the page disconnects you.
